# LOCK ARSENAL

## DESCRIPTION
- This framework tries to mimic the elite vehicles or unlockable vehicles logic but with arsenal items. The functions locks the items found in `presets` folder (in this extension file) if the designated sector is on the enemy side, and will unlock them if the sector is on the player side.
- To edit its preset, use the custom.sqf file found in the `presets` folder of this extension. There is a list of items already in the file to serve as an exemple.
- To visualize what items the sector unlocks, the player must open the map and click on the Arsenal+ marker found underneath the sector's marker.
