# RALLY POINT

## DESCRIPTION
- Inspired by BF2:Project Reality's rally point system, this is an addional redeploy option for the players in liberation.
- The rally point system is aimed to teleport players to the nearest squad mates in combat. It will apper in the Liberation's respawn/redeploy menu.
- Requires `ACE`.
- It's configurable through `CBA addon options`.
- It can be disabled in the `mission parameters`.
- There are two kinds of rally point: Squad and Commander/Team RP. Explanation with default configuration.
    - The squad rally point is only avaiable for squad mates (in Arma's word: same group). The leader can deploy it if there are 2 members nearby and if it has the required items (if configurated). Cannot deploy it near enemies and it will disappear if the leader dies/respawns or the leadership of the squad/group changes.
    - The commander rally point is for the team/side and it will be visible for everyone. It can be deployed if there are two group leaders nearby and if the commander has the required items (if configurated).
- Be aware that it can cost respawn resources (if enabled), if the rally point is < (FOB's range * 4) (i.e: 125*4 = 500m) of the nearest FOB!
