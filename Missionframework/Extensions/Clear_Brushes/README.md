# CLEAR BRUSHES

## DESCRIPTION
- This is a mod from [ampersand38](https://github.com/ampersand38/Brush-Clearing) adapted for liberation.
- It ables the player to cut down trees/brushes and grass.
- Requires ACE. Configurable in CBA options.
- The action is available in the ACE interaction menu, in Equipaments, once the player looks at a tree/bush/grass.
